Where jobs run

In this tab is the default and needs nothing: the Luau VM is compiled to WebAssembly and the pipeline runs on Python in the page. The first run downloads about 16 MB and Python is slower here than native, so for a big script you may prefer a local server, which runs the identical pipeline at full speed: 

git clone https://github.com/riftwarewtf/deobf
cd deobf
python deobf/build_luau.py --portable     # once: builds the patched Luau
pip install -r web/requirements.txt
python web/server.py                      # http://127.0.0.1:8000

Or with Docker: docker compose up --build — same address.

If this page is served over HTTPS, a http://localhost backend is fine, but a backend on another machine has to be HTTPS too — browsers block the mixed request otherwise.
